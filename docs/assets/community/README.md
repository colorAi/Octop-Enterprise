# Community QR codes

`octop-group-20261103.jpg` is the current WeChat group QR code shown in `README.md`, `README_CN.md` and `README_EN.md`. It preserves the supplied image without altering the QR pattern and is used in both light and dark mode.

Group invites expire; the current image states that it is valid before November 10, 2026. To refresh:

1. Obtain a fresh group invite image without redrawing or regenerating the QR pattern.
2. Save it here as `octop-group-YYYYMMDD.jpg` with the refresh date.
3. Update the image paths in all three READMEs and the validity information here.
4. Verify the new image and remove unreferenced expired QR images.
