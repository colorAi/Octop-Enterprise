# Community QR codes

`octop-group-20261124.png` is the current WeChat group QR code shown in `README.md` and `README_EN.md`. Refreshed on November 24, 2026, it preserves the supplied image without altering the QR pattern and is used in both light and dark mode.

To refresh:

1. Obtain a fresh group invite image without redrawing or regenerating the QR pattern.
2. Save it here as `octop-group-YYYYMMDD` with the refresh date and the original file extension.
3. Update the image paths in both READMEs and record the refresh date here.
4. Verify the new image and move unreferenced expired QR images to the local `.internal/docs/community/` archive.
