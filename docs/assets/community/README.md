# Community QR codes

`octop-group-20261110.png` is the current WeChat group QR code shown in `README.md` and `README_EN.md`. It preserves the supplied image without altering the QR pattern and is used in both light and dark mode.

Group invites expire; the current image states that it is valid before November 17, 2026. To refresh:

1. Obtain a fresh group invite image without redrawing or regenerating the QR pattern.
2. Save it here as `octop-group-YYYYMMDD` with the refresh date and the original file extension.
3. Update the image paths in both READMEs and the validity information here.
4. Verify the new image and remove unreferenced expired QR images.
