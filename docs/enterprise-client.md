# Octop Enterprise 企业客户端

[English](enterprise-client_EN.md)

## 员工开始使用

1. 向管理员获取服务器地址、账号和与服务器匹配的安装包。
2. 展开登录按钮下方的“服务器地址”，填写企业服务器根地址，再输入账号密码登录。省略协议时使用 HTTPS；只有部署方明确使用内网 HTTP 时才填写 `http://`。
3. 登录后，进入智能体聊天，在项目侧栏点击“添加项目文件夹”，通过系统窗口选择要处理的目录。
4. 在该项目中选择专家并新建对话。输入需要处理的文件或项目要求，完成后从成果卡片打开对应文件位置。

勾选“记住登录状态”后，客户端可在登录凭证仍有效时恢复登录；密码不会保存。退出账号会断开当前设备会话。

Windows 再次打开客户端会唤起已运行的窗口。覆盖安装后若原本的本地界面端口不可用，客户端会自动恢复到可用端口；这次恢复可能需要重新登录一次，账号配置和项目文件保留。

## 项目、专家与本机工具

支持多项目的客户端会保存这个企业账号在本机选择的项目。新对话默认使用当前项目，可以切换到已保存的项目或添加另一个文件夹。新旧本机对话统一从所属项目进入，切回项目后可继续查看和使用其中的会话。

侧栏顶部固定提供“添加项目文件夹”，下方按文件夹分层显示项目和对话：点击文件夹展开或折叠，可以同时展开多个项目；点击下一级对话继续聊天。文件夹右侧“＋”可选择专家并在该项目新建对话，“…”可管理该项目。展开、折叠文件夹只改变列表显示，不会切换当前聊天。

启动后，项目列表、已授权目录和项目会话列表可在本机工具仍在准备时加载。历史消息从公司服务器分页读取；执行新任务需要等待本机工具就绪。

输入框底部“添加附件”右侧的文件夹按钮只显示目录名称，悬停可查看完整路径。新对话可在这里选择已有项目或其他本地文件夹；已有对话始终使用原目录，选择其他项目会在目标项目新建对话。

每个对话固定所属项目和专家，新任务直接使用选中的文件夹。同一项目可以由不同专家分别开对话，共享项目文件，各自保留聊天记录。任务开始后切换项目不会改变原任务目录。同项目以及目录相互包含的项目同时只执行一个任务，等待审批或结果待核对的任务也占用执行位置；不同项目沿用本机最多 4 个任务的总上限。

项目菜单支持重命名、从列表移除、撤销授权和重新定位目录。移除、撤权不会删除项目文件或历史。目录移动后使用“重新定位”，原项目身份和对话保留；活动或待核对任务必须先处理，历史成果仍记录原路径。重新打开相同文件夹会复用已有项目。

旧本机对话按执行记录关联原来的目录，不搬动文件；缺少本机目录记录的历史不会自动获得当前项目的访问权。只有客户端、工具环境和公司服务均支持时才启用多项目。旧单目录模式保留“本地工作目录”中的选择和更换文件夹操作；旧版默认目录不自动成为所有新会话的项目。

在桌面客户端的“本地工作目录”页面，点击“检查工具”检查本地执行引擎，展开“工具详情”查看工具版本。

## 文件、模型与历史

项目文件保存在当前电脑的授权目录中。公司服务器保存账号、专家定义、长期记忆、正式会话和恢复记录；本机在项目目录之外保存执行检查点、操作回执和待同步记录。

项目文件面板和输入框的 `@` 文件引用使用当前对话绑定的本机目录。可预览文本和图片，其他文件可打开本地位置。共享目录中的任意文件变化不会自动作为当前回复的成果；文件工具写入的成果及明确交付的文件会进入当前任务记录。

每次提问前，客户端自动向公司服务器召回相关记忆；对话同步后，由服务器记录可检索的用户消息和回复。明确要求记住的信息通过服务端记忆工具保存。记忆按员工的专家实例隔离，旧专家可继续使用服务器原有的 SQLite 记忆，新实例使用部署配置指定的服务端存储。客户端关闭个人记忆库和专家初始化流程；项目里的文档不会自动作为个人记忆加载。

管理员改用专家分配后，有旧会话的个人专家仍以“历史”入口保留。打开旧会话后可点击“继续对话”：能确认是同一专家时默认选择其当前实例；专家已更换时，可搜索并选择当前已分配的专家。续聊复制完整历史上下文，原会话保留，不恢复旧任务的待执行操作。能唯一对应到同一员工、同一模板的旧专家，其服务端记忆和个人资料会参与新实例的召回；存在多个候选时不会自动混合，不复制其他员工或管理员的个人资料。

删除、移动等命中工具守卫的本机命令会显示审批卡片。批准后执行，拒绝或取消会保留未执行的操作；同一轮多个危险命令分别审批。可以为当前会话选择自动批准。切换页面后会恢复仍在运行的待审批请求；客户端进程退出后的中断任务不会自动重放命令。

本机完成任务后，短暂的同步失败不会将已完成结果改成执行失败。设置中的“本地工作目录”会提示等待同步，客户端在连接恢复后自动补传；重新登录后也会核对并补传已有记录。同一会话继续执行前须完成上次同步，已完成的工具操作不会因补传而重做。

本机命令默认最多执行 15 分钟，工具可为单次命令指定不超过 1 小时的超时。命令执行中可查看输出；模型流连续 10 分钟没有数据时结束该次请求。模型尚未开始返回时发生的临时超时、限流或连接故障最多重试三次；已经开始返回的模型流不会自动重发。推理强度和问答、计划、执行模式使用本轮选择，计划模式仅允许写入计划文件。

模型推理由公司配置的服务完成，任务执行需要连接企业服务器与模型服务。文件名、完成任务需要的摘录和工具结果可能发送给这些服务；整个项目不会自动同步。通过聊天上传、转发的图片和文件会进入企业服务器；支持附件导入的客户端会将所选附件复制到当前本机任务目录后再处理。终端/Python 具有当前系统用户权限，目录选择本身不能限制任意进程访问。

其他设备可以查看权限范围内的历史，但不会自动取得原电脑上的文件或接管运行进程。旧服务器会话可在企业客户端选择项目文件夹后点击“继续对话”，带上完整历史在本机继续。专家仍可用且会话已绑定本机项目时，直接在原会话发送消息即可。历史续聊需要公司服务器和客户端均支持此功能。

## 消息与成果转发

群聊中输入 `@` 或点击“@同事”可选择当前群成员，支持按姓名、群昵称和职位搜索；也可右键同事的消息头像，选择 `@姓名` 插入。被提及者会在消息中看到“@我”。专家入群暂不支持。

员工提问、agent 回复及生成成果下方的“转发”可选择企业员工、自己已加入且允许发言的群聊，或自己已启用的 agent。同事聊天和群聊消息也使用同一个入口，可多选目标。转给 agent 会新建会话并开始处理；成功结果可直接打开，部分失败时可在原弹窗中重试，已成功目标不会重复发送。

转发窗口可分别勾选原消息文字、每张图片和每个文件，也可直接选择“仅图片”或“仅文件”；图片提供缩略图，支持多图中只转发指定图片。选择目标后可填写补充说明，例如“整理这份文件并列出待办”；所选附件和要求会在同一次 agent 请求中发送。开始发送后固定本次内容和说明，失败重试不会重复发送已成功的部分；修改内容需关闭后重新转发。

发给员工或群聊的本机成果会按消息中的 SHA-256 校验原文件，再上传为企业聊天附件；接收方按企业聊天权限查看或下载。转给本机 agent 时，新对话使用当前项目，附件保存到目标会话所属项目的 `inbound` 目录；本机 agent 之间转发成果时复制文件并保留原件。单文件上限 50 MiB，超长文字和多附件按聊天限制拆分发送。

本机文件传输需要包含此功能的企业客户端壳，并使用成果所在电脑和已授权工作目录。只有网页更新、客户端壳未更新时，本机文件转发会提示缺少支持；纯文字转发仍可使用。转发不会自动开启群机器人或同步整个工作目录。

## 企业知识库

管理员在“知识库”页面统一创建知识库、配置检索模型并维护文档。在“管理 → 用户管理”编辑员工账号时，可在“知识库权限”中勾选该员工可用的知识库；“公司架构 → 员工设置”中的“知识库”标签也可调整同一份授权。知识库授权由管理员账号管理，不随专家或技能分配自动授予。

员工在“知识库”页面查看已授权资料，在聊天中选择知识库或点击“添加到聊天”进行检索，无需自行创建知识库。授权提供读取和检索权限，不允许员工修改管理员维护的文档。取消授权后，员工无法继续读取或检索该知识库；已存在的个人资料保留。

“全员共享”的知识库对全员可见。需要仅对指定员工开放时，关闭知识库的“共享”，再在员工设置中分配。授权保存后会通知员工更新配置，离线客户端恢复连接后也会检测变更；读取和检索权限由服务器即时检查。

## 员工可用模型

管理员在“公司架构 → 员工设置 → 模型设置”中，从已配置且可用的对话模型中勾选员工可使用的模型；“管理 → 用户管理”的员工编辑页也可调整同一份分配。只有管理员账号可以修改模型分配。

新员工和未分配模型的已有员工默认不能使用模型。管理员新增模型后，需要另行分配给员工；相同模型在不同提供商下分别授权。自动选模、视觉模型切换和企业本机任务都只使用已分配的模型。管理员账号可使用全部可用模型。

取消分配后，服务器会拒绝该员工后续的模型调用，包括当前任务的下一次调用；已经发出的模型请求不会因此回滚。保存分配后会通知员工更新配置。

## 权限、配置与软件更新

管理员调整员工角色、权限或策略后，会自动通知对应员工。模型授权及其他功能配置保存后，管理员也可在左侧“管理 → 应用设置”的“应用更新”标签中发布配置通知。收到“企业配置有更新”时，在任务执行或准备、等待工具审批、编辑本机消息、上传附件、未发送附件或排队消息、录音或转写、浏览器录制或回放等操作结束后点击“更新配置”，无需退出客户端；登录状态和已保存草稿保留。

新增授权的菜单按默认分组补入，之前手动隐藏的入口和自定义排序保留。撤销权限由服务器立即执行，不能通过选择“稍后”继续使用。

“更新配置”只应用现有程序支持的权限与功能配置。新的客户端界面、程序或工具环境需要安装管理员提供的新版本。具体区别见[更新说明](updates.md)。

## 能力范围与限制

- 企业客户端支持单专家本机任务；手动将成果转给其他专家已支持，多专家团队自动协作尚不支持。
- 支持在任务开始前导入当前专家已上传的图片和文件，也支持从企业消息转发附件；需要包含附件导入功能的客户端，不能直接导入任意外部链接。任务运行中的“插入”目前只支持文字，不能插入附件。
- 知识库由管理员配置并授权；本机任务可检索所选企业知识库，检索在公司服务器完成。
- 本机运行时不加载外部连接器或 ACP 编程工具。服务端保留的连接器、浏览器、终端及 ACP 等能力还受权限和 Docker 隔离策略限制，不能视为员工电脑的本机能力；定时任务与外部 IM 通道也是服务端入口。
- 当前不支持群机器人和 AI 群聊总结。
- 不同平台的安装、签名、公证和真实硬件验证状态见对应发行说明。
- 已完成的写入或生图不能因断线而盲目重做。遇到结果未知时，先检查原任务、文件和恢复状态。

## 管理员与构建者

服务端须启用设备通道及企业本机运行时，并提供匹配的专家、模型授权和通信配置，见[企业部署](../docker/enterprise/README.md)。

桌面壳和包内 Python 工具环境需要一同构建。离线依赖、目标架构验证和参数见[中文客户端构建指南](client-build.md)。上游独立个人版客户端不应替代本项目企业客户端。

本仓库提供源码。管理员按桌面说明构建与服务器匹配的企业客户端，并分发给员工。
