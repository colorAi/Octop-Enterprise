# Octop Enterprise 企业客户端

[English](enterprise-client_EN.md)

## 员工开始使用

1. 向管理员获取服务器地址、账号和与服务器匹配的安装包。
2. 展开登录按钮下方的“服务器地址”，填写企业服务器根地址，再输入账号密码登录。省略协议时使用 HTTPS；只有部署方明确使用内网 HTTP 时才填写 `http://`。
3. 登录后，打开左侧菜单“设置”分组下的“本地工作目录”，确认当前目录。如需使用已有项目，点击“更换文件夹”；尚无目录时点击“选择文件夹”。
4. 选择专家，新建任务。输入需要处理的文件或项目要求，完成后从成果卡片打开对应文件位置。

勾选“记住登录状态”后，客户端可在登录凭证仍有效时恢复登录；密码不会保存。退出账号会断开当前设备会话。

## 默认目录与本机工具

首次在这台电脑使用某个企业账号时，客户端会自动创建并授权默认工作目录。Windows 优先使用安装目录下的 `Workspace`，不可写时回退到用户目录下的 `Octop Workspace`；macOS 使用用户目录下的 `Octop Workspace`。各企业账号使用各自的子目录，实际路径以“本地工作目录”页面为准。

更换目录时，通过系统文件夹选择窗口选择并授权。客户端按企业地址和员工账号分别保存目录。“移除目录”取消当前目录授权并保留项目文件，之后可重新选择目录。已保存的目录不可访问时，页面会提示重新选择。

在桌面客户端的“本地工作目录”页面，点击“检查工具”检查本地执行引擎，展开“工具详情”查看工具版本。

## 文件、模型与历史

项目文件保存在当前电脑的授权目录中。公司服务器保存账号、专家定义、长期记忆、正式会话和恢复记录；本机保留必要缓存和操作回执。

模型推理由公司配置的服务完成，任务执行需要连接企业服务器与模型服务。文件名、完成任务需要的摘录和工具结果可能发送给这些服务；整个项目不会自动同步。通过聊天上传、转发的图片和文件会进入企业服务器；支持附件导入的客户端会将所选附件复制到当前本机任务目录后再处理。终端/Python 具有当前系统用户权限，目录选择本身不能限制任意进程访问。

其他设备可以查看权限范围内的历史，但不会自动取得原电脑上的文件或接管运行进程。旧服务器任务在企业客户端中只读，需要本机继续工作时请新建会话。

## 消息与成果转发

员工提问、agent 回复及生成成果下方的“转发”可选择企业员工、自己已加入且允许发言的群聊，或自己已启用的 agent。同事聊天和群聊消息也使用同一个入口，可多选目标。转给 agent 会新建会话并开始处理；成功结果可直接打开，部分失败时可在原弹窗中重试，已成功目标不会重复发送。

转发窗口可分别勾选原消息文字、每张图片和每个文件，也可直接选择“仅图片”或“仅文件”；图片提供缩略图，支持多图中只转发指定图片。选择目标后可填写补充说明，例如“整理这份文件并列出待办”；所选附件和要求会在同一次 agent 请求中发送。开始发送后固定本次内容和说明，失败重试不会重复发送已成功的部分；修改内容需关闭后重新转发。

发给员工或群聊的本机成果会按消息中的 SHA-256 校验原文件，再上传为企业聊天附件；接收方按企业聊天权限查看或下载。转给本机 agent 的附件保存到目标会话的任务目录，本机 agent 之间转发成果时复制文件并保留原件。单文件上限 50 MiB，超长文字和多附件按聊天限制拆分发送。

本机文件传输需要包含此功能的企业客户端壳，并使用成果所在电脑和已授权工作目录。只有网页更新、客户端壳未更新时，本机文件转发会提示缺少支持；纯文字转发仍可使用。转发不会自动开启群机器人或同步整个工作目录。

## 权限、配置与软件更新

管理员调整员工角色、权限或策略后，会自动通知对应员工。模型授权及其他功能配置保存后，管理员也可在左侧“管理 → 应用设置”的“应用更新”标签中发布配置通知。收到“企业配置有更新”时，在任务执行或准备、等待工具审批、编辑本机消息、上传附件、未发送附件或排队消息、录音或转写、浏览器录制或回放等操作结束后点击“更新配置”，无需退出客户端；登录状态和已保存草稿保留。

新增授权的菜单按默认分组补入，之前手动隐藏的入口和自定义排序保留。撤销权限由服务器立即执行，不能通过选择“稍后”继续使用。

“更新配置”只应用现有程序支持的权限与功能配置。新的客户端界面、程序或工具环境需要安装管理员提供的新版本。具体区别见[更新说明](updates.md)。

## 能力范围与限制

- 企业客户端支持单专家本机任务；手动将成果转给其他专家已支持，多专家团队自动协作尚不支持。
- 支持在任务开始前导入当前专家已上传的图片和文件，也支持从企业消息转发附件；需要包含附件导入功能的客户端，不能直接导入任意外部链接。任务运行中的“插入”目前只支持文字，不能插入附件。
- 知识库由管理员配置并授权；本机任务可检索所选企业知识库，检索在公司服务器完成。
- 本机运行时不加载外部连接器或 ACP 编程工具。服务端保留的连接器、浏览器、终端及 ACP 等能力还受权限和 Docker 隔离策略限制，不能视为员工电脑的本机能力；定时任务与外部 IM 通道也是服务端入口。
- 当前不支持群机器人和 AI 群聊总结。
- 不同平台的安装、签名、公证和真实硬件验证状态见对应发行说明。
- 已完成的写入或生图不能因断线而盲目重做。遇到结果未知时，先检查原任务、文件和恢复状态。

## 管理员与构建者

服务端须启用设备通道及企业本机运行时，并提供匹配的专家、模型授权和通信配置，见[企业部署](../docker/enterprise/README.md)。

桌面壳和包内 Python 工具环境需要一同构建。离线依赖、目标架构验证和参数见[桌面构建说明](../desktop/README.md)（English）。上游独立个人版客户端不应替代本项目企业客户端。

本仓库提供源码。管理员按桌面说明构建与服务器匹配的企业客户端，并分发给员工。
