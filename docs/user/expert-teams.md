# 专家团队

专家团队由主持专家和至少两名普通专家组成。主持人分配任务，成员以自己的名称和头像发言，最后由主持人汇总。团队模式与同事群里的[群聊专家](group-experts.md)是两个功能。

## 创建和使用

1. 在专家页面打开“我的团队”，配置名称、模型和成员。
2. 从聊天侧栏打开团队并提交任务。新消息先交给主持人，主持人可以同时分配给不同成员。
3. 成员使用自己的工具、工作区和记忆处理任务，完成后回报主持人。

团队中的 `@` 是主持人派工时的优先提示，不保证只有被提及的成员参与。需要在同事群中指定一位专家回答时，使用群聊专家入口。

## 边界

- 成员必须是普通专家，不能嵌套团队；可使用自己的专家和已分享给自己的专家。
- 主持人负责协调，不提供成员的文件、浏览器或插件工具。团队没有一个供所有成员共同写入的工作区。
- 有在途派工时不能移出该成员或删除对应专家。
- 停止当前聊天只停止主持人本轮，已经派出的成员任务仍可完成并回报。
- 团队绑定通道时绑定主持人。团队不支持分享；进程重启不会恢复进程内尚未完成的派工。

实际可用菜单和专家仍受当前账号授权及部署方式限制。
