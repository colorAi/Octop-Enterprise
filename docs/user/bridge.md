# 远程实例桥接

远程桥接连接另一个 Octop 实例。在本机浏览器中查看该账号可访问的远程专家，并将聊天和文件请求交给专家所在实例执行。

## 连接

1. 确认当前账号有相应菜单权限，并能访问对端实例的登录地址。
2. 打开“设置 → 远程桥接”，填写对端地址、账号、密码和连接显示名。
3. 使用“探测”检查登录与可见专家，再保存并连接。
4. 在聊天页面选择远程入口和专家。连接失败时检查对端服务、地址、证书及该账号权限。

远程请求以该账号在对端的身份执行，不扩大专家和资源权限。文件上传到专家所在实例，聊天历史以对端保存的记录为准。远程工作区不会复制成本机项目目录。

全局模型、连接器、知识库管理等需要在对端管理页面操作。远程桥接与[企业客户端本机任务](enterprise-client.md)、[群聊专家](group-experts.md)分别使用各自的执行入口。
