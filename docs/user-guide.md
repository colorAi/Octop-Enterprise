# Octop Enterprise 使用指南

[English](user-guide_EN.md)

本指南面向当前企业版。管理员部署企业服务器并配置账号、模型与权限，员工使用企业客户端处理本机任务，并通过公司通讯录、私聊和群组协作。

## 管理员开始使用

1. 按部署指南准备 Linux、Docker、数据库和通信服务，首次安装执行 `octop init` 创建管理员。
2. 浏览器打开已配置的企业地址，以管理员账号登录。
3. 在左侧“管理 → 模型”配置模型服务，在“管理 → 用户”准备员工账号、角色和权限，并准备供员工使用的专家。
4. 分发匹配的企业客户端，验证一名员工的本机任务、消息、附件和成果后再扩大使用。

需要设置每位员工可用的专家和技能时，在“管理 → 用户 → 公司架构”选择资源来源、维护部门范围，再通过员工行的“专家管理”“技能管理”分配；所属部门和职位在“基本设置”中维护，见[给员工分配专家和技能](expert-assignments.md)。

`octop init` 用于首次创建管理员账号，仅在首次安装时执行。数据库、密钥和恢复步骤以部署指南为准。

## 员工开始使用

1. 在登录页展开“服务器地址”，填写管理员提供的地址，再输入账号密码。没有协议前缀时默认使用 HTTPS，内网 HTTP 必须明确填写 `http://`。
2. 登录后，在左侧“设置”分组下打开“本地工作目录”，确认自动创建的默认目录；处理已有项目时可点击“更换文件夹”。
3. 从“Agent”入口选择专家、新建任务，描述需要处理的文件或项目。
4. 查看任务产出，在系统文件管理器中定位本机成果；也可转发给同事、群聊或其他专家。

默认目录规则、附件导入、权限与数据边界见[企业客户端指南](enterprise-client.md)。

## 常用功能位置

以下是默认导航名称；实际显示由账号权限、客户端类型和自定义菜单布局决定。

| 功能                         | 入口                                       |
| ---------------------------- | ------------------------------------------ |
| AI 对话和任务                | 左侧“Agent”                                |
| 专家配置与模板               | 左侧“专家”                                 |
| 公司通讯录、同事消息和群聊   | 左侧“公司”；配置公司名后显示自定义名称     |

配置更新用于刷新权限和功能配置；界面、原生程序和工具环境变化通过匹配的软件发行更新。

## 使用范围

企业客户端以单专家本机任务为主，支持处理项目文件、图像和文档，以及在兼容客户端中导入上传或转发的附件。本机任务可检索有权使用且已配置的企业知识库。

多专家团队自动协作、外部连接器和 ACP 不属于当前本机运行时能力。上游保留的浏览器、终端、连接器、ACP、定时任务和外部 IM 通道属于服务端功能，受部署、权限及隔离策略限制。

项目文件不会随历史记录自动同步到另一台电脑。本机工具使用当前系统账号权限，工作目录不是操作系统沙箱；通过聊天上传或转发的附件会进入企业服务器。
